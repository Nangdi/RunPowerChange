# 85형 관전 화면 설명 그림

85형 화면 아래 칸은 **오늘의 랭킹 → 설명 그림 1 → 설명 그림 2** 순서로 `spectatorInfoSeconds`(기본 10초)마다 바뀝니다.
설명 그림은 실행할 때 이 폴더의 파일을 읽으므로, 빌드 후에도 `<앱>_Data/StreamingAssets/Spectator/` 의 파일만 바꾸면 다시 빌드하지 않고 반영됩니다 (앱 재시작 필요).

| 파일 | 내용 | 크기 |
|---|---|---|
| `info_1.png` | 왜 그럴까요? (움직임 → 발전 → 송전 설명) | 2028 x 772 (투명 배경 PNG) |
| `info_2.png` | 우리와 어떤 관련이 있을까요? | 2028 x 772 |

- 같은 크기로 만들어야 화면의 같은 자리에 맞게 들어갑니다. 크기가 다르면 비율을 지켜 칸 안에 맞춰집니다.
- 파일이 없거나 깨져 있으면 앱에 들어 있는 기본 그림을 쓰고 로그만 남깁니다.
- 원본은 디자이너 PSD(80인치 화면) 의 `02-내용1`, `03-내용2` 그룹이고, `Tools/psd_export.py` 를 실행하면 이 폴더에도 다시 써집니다.
