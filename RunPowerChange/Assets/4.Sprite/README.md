# 달려라! 전력 챌린지 - 화면 이미지 교체 안내

| 화면 | 해상도 | 비고 |
|---|---|---|
| 32형 쳇바퀴 화면 (2대, 같은 구성) | **1920 x 1080** 가로 | 모든 화면 뒤에 3D 경주 장면이 보인다. 정적 PNG 배경은 **투명**으로 둔다 |
| 85형 관전 화면 | **1080 x 1920** 세로 | 2160 x 3840 모니터도 같은 비율이라 그대로 커진다. Player 칸 자리는 3D 화면이 그리므로 **투명**으로 둔다 |

## 교체 방법

- 아래 폴더의 PNG를 **같은 파일명으로 덮어쓰기** 하면 씬·프리팹 수정 없이 바로 반영됩니다.
- 파일을 지우고 새로 넣지 마세요. 연결이 끊어집니다.
- 임포트 설정(스프라이트, 압축)은 자동으로 맞춰집니다.

| 폴더 | 내용 |
|---|---|
| `Static/Static_<화면>.png` | 화면별 고정 글자 + 카드 + 라벨 (정적 레이어 1장, 배경 투명) |
| `Parts/*.png` | 버튼, 카드, 게이지 등 따로 움직이거나 눌리는 요소 |
| `_Guide/Guide_<화면>.png` | 작업용 가이드. **분홍 박스 = 프로그램이 그리는 자리** (정적 PNG에 그리지 말 것) |

| CharacterSelect | 제목 | 캐릭터 카드 2장(버튼), 선택 테두리, 안내 문구, 대기 문구, 남은 시간 바 |

| Transmit | HUD 카드(라벨·단위), 타이머 원, 하단 바, 가상 조건 안내 | 전압 표시, 출발·손실·도착 값, 타이머, 도착 전력 바·숫자 |
| Result | 제목, 결과 카드(라벨·단위), 랭킹 머리줄, 하단 안내 | 결과 값, 판매 금액, 단가 안내, 랭킹 줄, 남은 시간 바 |

## 글꼴과 색 (디자인 시안 기준)

- 글꼴: Noto Sans KR (Bold = 제목·값·버튼, Medium = 본문)
- 카드 반투명 흰색, 남색 `#2E3154`, 주황 `#F26A3D`, 초록 `#2DB36F`, 파랑 `#3A86D6`, 노랑 `#F2A81D`, 85형 바탕 `#ECECF1`
- 글꼴에 없는 기호(가운뎃점 `·` 등)는 □로 나오므로 쓰지 않는다.

## 3D (임시)

- 트랙: 씬 `Race/Track` (디자이너 3D 맵으로 교체). 코스는 `Race` 의 +Z(12시 방향) 직선, 1유닛 = 1m.
- 캐릭터: `2.Model/Prefabs/RunPowerChange/Characters/Character_Ssadori`, `Character_Dino` (같은 이름으로 프리팹 교체). Animator 가 있으면 `Speed`(m/s) 값을 받는다.
