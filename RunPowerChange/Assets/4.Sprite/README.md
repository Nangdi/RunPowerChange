# 달려라! 전력 챌린지 - 화면 이미지 교체 안내 (32형 쳇바퀴 화면)

화면 해상도: **1920 x 1080** (쳇바퀴 내부 32형 터치모니터, 쳇바퀴 2대가 같은 화면 구성을 씀)

## 교체 방법

- 아래 폴더의 PNG를 **같은 파일명으로 덮어쓰기** 하면 씬·프리팹 수정 없이 바로 반영됩니다.
- 파일을 지우고 새로 넣지 마세요. 연결이 끊어집니다.
- 임포트 설정(스프라이트, 압축)은 자동으로 맞춰집니다.

| 폴더 | 내용 | 크기 |
|---|---|---|
| `Static/Static_<화면>.png` | 화면별 배경 + 고정 글자 + 상자 (정적 레이어 1장) | 1920 x 1080 |
| `Parts/*.png` | 버튼, 카드, 게이지 등 따로 움직이거나 눌리는 요소 | 아래 표 |
| `_Guide/Guide_<화면>.png` | 작업용 가이드. **분홍 박스 = 프로그램이 그리는 자리** (정적 PNG에 그리지 말 것) | 1920 x 1080 |

## 화면 목록 (순서대로 진행)

| 화면 | 정적 레이어에 들어가는 것 | 프로그램이 그리는 것 (분홍 박스) |
|---|---|---|
| Idle | 전시명, 타이틀, 설명, 터치 안내 | 시작 버튼 그림, 화면 전체 터치 영역 |
| Guide | 체험 방법 3단계, 가상모델 안내문 | 시작하기 버튼 |
| Countdown | 준비 안내 문구 | 3·2·1·START 숫자 |
| Run | 상자 5개와 라벨·단위, 안내문 | 속도, 출력, 발전량, 거리, 남은 시간, 게이지 2개 |
| RunResult | 기록 상자 라벨·단위, 발전왕 상자 제목 | 기록 값, 순위, 백분위, 랭킹 줄, 다음 버튼 |
| Voltage | 제목, 보낼 전력 상자, 안내문 | 보낼 전력 값, 환산 설명, 전압 버튼 2개 |
| Transmit | 발전소·도시 그림, 값 상자 라벨·단위, 안내문 | 전압 이름, 송전선 게이지, 출발·손실·도착 값 |
| SaleResult | 기록 상자 라벨·단위, 판매왕 상자 제목 | 기록 값, 순위, 백분위, 단가 안내, 랭킹 줄, 다음 버튼 |
| Summary | 발전·판매 기록 상자 라벨·단위 | 기록 값, 순위, 송전 조건, 버튼 2개 |
| End | 감사 인사, 마무리 설명 | 없음 |

## 부품 (Parts)

글자가 들어간 부품은 **픽셀 크기를 그대로** 유지해 주세요. 크기가 다르면 비율에 맞춰 줄어듭니다.

| 파일 | 크기 | 비고 |
|---|---|---|
| `Button_Start.png` | 520 x 130 | 대기화면 시작 버튼 그림 |
| `Button_Confirm.png` | 480 x 110 | 시작하기 |
| `Button_Transmit.png` | 480 x 110 | 송전하러 가기 |
| `Button_Result.png` | 480 x 110 | 결과 보기 |
| `Button_Again.png` / `Button_Home.png` | 400 x 110 | 다시 체험 / 처음으로 |
| `Button_Low.png` / `Button_High.png` | 780 x 400 | 낮은 전압 / 높은 전압 선택 카드 |
| `Card_Bg.png`, `Gauge_Bg.png`, `RankRow_Bg.png` | 9-slice | **흰색**으로 두세요. 색은 프로그램이 칠합니다 |
| `Dot.png` | 64 x 64 | 흰 원 |

## 글꼴과 색

- 글꼴: Noto Sans KR (Bold = 제목·값·버튼, Medium = 본문)
- 강조색 `#FFC400`, 배경 `#0A1222`, 상자 `#182640`, 보조 글자 `#A0B0CC`
- 프로그램이 그리는 값 글자의 색·크기를 바꾸려면 개발자에게 알려 주세요.
