# 달려라! 전력 챌린지 - 화면 이미지 교체 안내

화면 이미지는 디자이너 PSD 에서 도구로 뽑는다. PSD 를 고친 뒤 아래 명령을 다시 실행하면 같은 파일명으로 덮어써져 씬·프리팹 수정 없이 반영된다.

```
python Tools/psd_export.py "<03-달려라 전력챌린지-프로그램용.psd>" "<03-달려라 전력챌린지(80인치화면)-프로그램용.psd>"
```
(필요: `pip install psd-tools numpy aggdraw`)

| 화면 | PSD | 해상도 |
|---|---|---|
| 32형 쳇바퀴 화면 (2대, 같은 구성) | 03-달려라 전력챌린지-프로그램용.psd | **1920 x 1080** 가로 |
| 85형 관전 화면 | 03-달려라 전력챌린지(80인치화면)-프로그램용.psd | **2160 x 3840** 세로 (1080 x 1920 모니터도 같은 비율로 줄어듦) |

- PSD 의 "배경 샘플" 레이어는 뽑지 않는다. 실행 화면에서는 그 자리에 Unity 3D 장면(디자이너 맵)이 보인다.
- 도구가 레이어를 **이름으로** 찾으므로 그룹·레이어 이름을 바꾸면 `Tools/psd_export.py` 의 이름 표도 같이 고친다.
- 부품 위치·크기를 바꿨으면 `4.Sprite/_Layout/psd_layout.json` 이 새로 써지므로, Unity 에서 프리팹을 다시 만든다
  (`PowerPrefabBuilder.BuildAll(rebuild: true)`). 위치가 그대로면 이미지 덮어쓰기만으로 끝난다.
- 파일을 지우고 새로 넣지 마세요. 연결(GUID)이 끊어집니다.

| 폴더 | 내용 |
|---|---|
| `Static/Static_<화면>.png` | 화면별 고정 글자·카드·라벨 (정적 레이어 1장, 배경 투명) |
| `Parts/*.png` | 버튼, 숫자 그림, 게이지, 순서대로 나타나는 카드 등 따로 움직이거나 눌리는 요소 |
| `_Layout/psd_layout.json` | 부품과 글자 자리의 PSD 좌표 (프리팹 생성 도구가 읽음) |
| `_Guide/Guide_<화면>.png` | 작업용 가이드. **분홍 박스 = 프로그램이 그리는 자리** |

## 32형 화면 (순서대로 진행)

| 화면 | PSD 그룹 | 프로그램이 그리는 것 |
|---|---|---|
| Idle | 01-대기화면 | 체험시작 버튼(숨쉬기 효과), 화면 전체 터치 |
| Join | 02-참가대기 | 문구 3종(기다림 / 참여 유도 / 준비하세요), 남은 초 숫자 그림 + 회전 원, 참여하기 버튼, PLAYER 01/02 READY·WAIT |
| WaitNext | (디자인 없음) | 02-참가대기 의 제목·배경을 쓰고 안내 문구는 글자로 그림 |
| Guide | 03-체험안내 | 하단 남은 시간 바 |
| Countdown | 04-카운트 | 3·2·1·GO 그림 |
| Run | 05-게임화면 | 속도(바늘·숫자), 남은 시간(원·숫자), ME/PLAYER 표시(시작 후 2초), 누적 환산 발전량 바·숫자 |
| Voltage | 06-고,저전압 선택화면 | 발전량, 순위, 고/저전압 버튼, 하단 남은 시간 바 |
| Sale | 07-전력판매 화면 | 카드 5개가 차례로 나타남, 발전량·판매 금액 숫자 |
| Ranking | 08-랭킹화면 | 1~5위 기록 시각·값, 나의 순위 줄 |

- 03-체험안내 3단계 카드의 **"제한시간 50초"** 는 그림에 들어 있다. 설정창에서 발전 시간을 바꾸면 PSD 문구도 바꿔서 다시 뽑아야 한다.
- 05-게임화면 하단의 **"100시간"** 문구도 그림이다. 판매 환산 시간(saleScaleMinutes)을 바꾸면 같이 바꾼다.
- 랭킹 표의 순위 숫자 1~5, 줄 구분선, 단위(wh, ₩)는 배경 그림에 있다. 표는 5줄 고정이다.

## 글꼴과 색 (디자인 PSD 기준)

- 문구: Paperlogy (Medium / SemiBold / Bold). 숫자: PSD 는 HG꼬딕씨 이지만 이 PC 에 글꼴이 없어 **Paperlogy ExtraBold** 로 대신한다.
  HG꼬딕씨 글꼴 파일을 받으면 TMP 폰트 에셋을 만들어 `PowerUIKit.Font(Weight.ExtraBold)` 를 바꾼다.
- 남색 `#34375A`, 발전량 주황 `#FA7255`, 순위 초록 `#57B588`, 강조 노랑 `#FBB03B`
- 글꼴에 없는 기호는 □로 나오므로 쓰지 않는다.

## 3D (디자이너 맵, HDRP)

- 원본: `Assets/runing/` (running.unitypackage). 디자이너 씬 `runing/save/running_R_007.unity` 에서
  **Tools > 달려라 전력 챌린지 > 5. 3D 경주 장면 만들기** 가 맵·조명·후처리·캐릭터·바퀴를 `RaceMap.prefab` 으로 묶고 카메라를 복사한다.
- 맵을 새로 받으면 패키지를 같은 경로에 덮어쓰고 메뉴 5 를 다시 실행한다.
- 캐릭터는 제자리에서 뛰고 기둥·유리벽이 다가온다. 흐르는 빠르기 = 지금 가장 빠른 체험자 속도. 결승선은 끝나기 `finishApproachSeconds` 전부터 다가온다.
- 레인: 쳇바퀴 1 = 왼쪽 파랑 레인(사람), 쳇바퀴 2 = 오른쪽 분홍 레인(공룡). 혼자 달리면 빈 레인에 오늘(없으면 전날) 1위 기록이 반투명으로 달린다.
- 은하수 하늘 HDR(`8k HDRI Galaxy Backgrounds`)은 원본이 110MB 로 GitHub 제한(100MB)을 넘어 4096x2048 로 줄여 넣었다.
